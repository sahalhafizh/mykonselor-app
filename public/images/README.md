# Asset Branding

Asset branding lokal yang digunakan:

- `logo-unpam.png`: versi 512x512 untuk navbar dan komponen brand.
- `favicon-unpam.png`: versi 64x64 untuk ikon tab browser.

Kedua file dibuat dari logo Universitas Pamulang yang diberikan oleh pemilik project pada 30 Agustus 2026. Layout tetap memiliki fallback ikon akademik apabila asset logo dihapus atau tidak tersedia.
